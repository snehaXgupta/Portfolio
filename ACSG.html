Automated Class Schedule Generator (ACSG)

TypeScript & JS ● DEPLOYED

The **Automated Class Schedule Generator** is a responsive, web-based algorithmic scheduler designed to compile collision-free class sheets for academic institutions based on specific parameters such as tutor availability, lecture durations, student groups, and room allocations.

🎯 Key Features

  • **Conflict Checker Algorithm**: Real-time checking logic preventing student, tutor, or classroom double-bookings.
  • **Load Balancing**: Allocates teacher hours evenly across week plans to prevent staff over-scheduling.
  • **Interactive HTML Timetable Grid**: Instantly plots schedules in a custom CSS Grid template rendering responsive, high-contrast visual timetables.
  • **Dynamic Configurations**: Allows editing student groups, classes, subjects, and room capacities directly in-browser.

🛠️ Tech Stack & Architecture

Built as a zero-dependency frontend application prioritizing client-side efficiency, speed, and algorithmic correctness:

  • **TypeScript**: Core algorithmic data structures and scheduler engines.
  • **HTML5 & CSS Grid**: Render elements displaying final schedules.
  • **Local Storage**: Persists timetables across browser tabs.
