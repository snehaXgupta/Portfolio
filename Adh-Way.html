Adhway Prahari (Road & Journey Sentinel)

PHP-Laravel & Leaflet ● DEPLOYED

**Adhway Prahari** (literally translating to *Journey Sentinel* in Sanskrit/Hindi) is a real-time transit-tracking and safety system. It logs device coordinate streams, verifies journey path safety against pre-configured routes, and displays live analytics in a visual control panel dashboard.

🎯 Key Features

  • **Real-Time Coordinates Logging**: Receives spatial telemetry data over secure channels, tracking vehicle coordinates continuously.
  • **Interactive Mapping Engine**: Renders maps dashboards utilizing Leaflet JS integration, tracing journey paths dynamically.
  • **Safety Alerts & Notifications**: Automates checks to flag when a tracked device deviates from its planned safety corridor.
  • **Relational Data Analytics**: Implements MySQL schemas to index coordinates history, driver data, and security events.

🛠️ Tech Stack & Architecture

A secure full-stack architecture built to manage real-time coordinates streams efficiently:

  • **Backend Framework**: PHP (Laravel) with robust API routing and controller logic.
  • **Frontend View Engine**: Blade templates with Vanilla JS and CSS layouts.
  • **Geospatial Tracking**: Leaflet JS map APIs for location-based rendering.
  • **Storage**: Relational MySQL Database with indexing on coordinates logs.
